# gh-issue-decompose

Decompose a parent GitHub issue into child issues with required parent links in each body.

## Install

```bash
./install.sh gh-issue-decompose
```

## Usage

```text
/gh-issue-decompose 123
/gh-issue-decompose https://github.com/OWNER/REPO/issues/123
decompose this into issues
file these as sub-issues of #123
break this epic into 4 issues
create child issues for #123
```
